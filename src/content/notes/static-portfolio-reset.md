## 背景

当前阶段更需要一个稳定、容易部署、方便长期维护的个人展示站，而不是一套线上内容管理系统。

## 决策

- 内容通过本地 Markdown 和 TypeScript 文件维护。
- 访客只浏览，不写入数据。
- 推送 GitHub 后交给 Netlify 自动构建。
