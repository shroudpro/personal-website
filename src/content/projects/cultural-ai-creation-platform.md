## Overview

项目围绕传统文化内容表达，将汉字含义、文化语义和视觉提示词组织为可生成的创意方案。

## My Role

- 页面流程设计
- 前端架构实现
- 生图 API 接入方案
- 项目包装与展示材料整理

## Core Features

- 汉字文化解析
- 提示词组织
- 海报视觉生成
- 文创方案展示

## Tech Stack

- Vue3
- ModelScope API
- Prompt Engineering

## Challenges & Solutions

- 文化语义难以直接转化为画面：将文字拆分为意象、材料、构图和色彩字段，再组合为稳定提示词。
- 生成效果需要保持统一气质：用固定风格词和展示模板控制输出，降低每次生成的视觉波动。

## Result

形成了从文化输入到视觉方案展示的完整原型，适合用于传统文化创新项目展示和答辩说明。
