## 记录

在多个竞赛项目中，先通过多轮讨论确认需求、技术栈和成功标准，再把 PRD 与 MVP 设计交给 agent 执行。开发过程按阶段推进，每轮都保留变更记录、工作报告和手动测试结果，再根据实际效果决定下一轮迭代方向。

## 收获

- AI 可以承担重复执行和整理工作，但项目取舍仍需要人来判断。
- 清晰的上下文、边界和验收标准会直接影响 agent 的输出质量。
- 小步提交、持续验证和可回溯文档让快速开发更容易保持稳定。
